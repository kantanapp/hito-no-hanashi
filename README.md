# 人の話をよく聞いて

お母さんに頼まれた買い物を**おぼえて**、上から落ちてくる品物をタップで取り、
頼まれた品と数をぴったり合わせる、かぞくみんなの「おつかいゲーム」です。

**あそぶ → https://kantanapp.github.io/hito-no-hanashi/**

スマホの縦持ちで遊べます（パソコンでも遊べます）。

## あそびかた

1. むずかしさを3つから選びます。
2. お母さんがお願いを言います。**スタートするとお願いは消えます**。おぼえてから「おぼえた！ いってきます」。
3. 品物が落ちてくるので、頼まれたものをタップしてカゴに入れます。
4. そろったと思ったら「レジへ」。**頼まれた品と数がぴったり**なら成功、ひとつでも違えば失敗です。

| | やさしい | ふつう | むずかしい |
|---|---|---|---|
| 場所 | やおや | スーパー | やおや → スーパー → ぎんこう |
| カゴの中身 | 見える | 見える | 見えない |
| 取り直し | できる | できない | できない |
| 電話 | なし | 買い物の途中で1回 | レジのあとに次のお願い |
| 読む時間 | 制限なし | 制限なし | 制限あり |

「かわないでね」と言われた品を買うと失敗です。音と声（お母さんの読み上げ）は、
タイトル画面の「こえ」「おと」で切り替えられます。成功回数はこのブラウザに保存されます。

## フォルダの中身

```
hito-no-hanashi/
├── index.html            ← ゲーム本体（これ1枚で動く。CSS・JavaScript も中に入っている）
├── SPEC.md               ← 仕様書（遊び方・ルール・演出・GA4 のイベントまで全部）
├── README.md             ← このファイル
├── icon.svg              ← ファビコン
├── apple-touch-icon.png  ← ホーム画面のアイコン（180×180）
├── ogp.png               ← SNSで共有したときの画像（1200×630）
└── tools/
    └── playtest.js       ← 通しテスト（任意）
```

フレームワークやビルドツールは使っていません。素の HTML / CSS / JavaScript です。
外から読み込むのは Google Fonts と GA4（gtag.js）だけです。

**直すときは `index.html` が正本です。** 詳しいルールと決めごとは [SPEC.md](SPEC.md) に書いてあります。

## 通しテスト（任意）

```
npm i -D playwright && npx playwright install chromium
node tools/playtest.js
```

スマホ幅（390×760・320×600）のブラウザで3つのむずかしさを最後まで動かし、
お願い文と50品の山・品物の重なり・電話・ハッピーエンド・GA4のイベントを確かめます。
最後に `ALL OK` が出れば合格です。
